# ContaAI v0.1.0

## Scop
Crearea fundației tehnice și a sistemului de autentificare.

## Funcționalități
- register, login și logout;
- JWT și refresh tokens;
- `/auth/me`;
- parole Argon2;
- dashboard inițial;
- Docker Compose;
- PostgreSQL, Redis și MinIO;
- FastAPI, Next.js, Alembic și worker.
