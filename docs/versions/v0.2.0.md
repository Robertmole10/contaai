# ContaAI v0.2.0

## Scop
Transformarea aplicației într-un workspace ERP multi-companie.

## Funcționalități
- organizații;
- companii multiple;
- memberships;
- roluri și permisiuni RBAC;
- onboarding;
- company switcher;
- dashboard ERP;
- sidebar modular;
- API workspace și organizații.

## Migrare bază de date
`0003_multi_tenancy`

## Upgrade față de v0.1.0
Versiunea 0.1 oferea autentificare și un dashboard simplu. Versiunea 0.2 adaugă structura multi-tenant necesară pentru administrarea mai multor entități și pregătește platforma pentru module contabile reale.
